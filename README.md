VisionGuard AI is a real-time smart surveillance system that uses Deep Learning and Computer Vision for human detection and face recognition. The system can identify known individuals, detect unknown persons, and improve recognition accuracy through adaptive learning techniques.

Features
1-Real-time CCTV monitoring
2-Face recognition using CNN embeddings
3-YOLO-based human detection
4-Cosine similarity matching
5-Image augmentation support
6-Edge AI deployment support
7-Adaptive learning for repeated faces
Technologies Used
1-TensorFlow / Keras
2-OpenCV
3-YOLO
4-CNN Architectures
5-MobileNetV1 / ResNet50
Workflow
1-Capture video from camera
2-Detect faces using YOLO
3-Extract facial embeddings
4-Compare embeddings using cosine similarity
5-Identify or store new faces
Future Scope
1-Threat detection
2-Multi-camera support
3-Mobile app integration
4-Cloud synchronization
5-Smart alert system
Applications
1-Smart CCTV systems
2-Campus security
3-Office monitoring
4-Smart attendance systems
